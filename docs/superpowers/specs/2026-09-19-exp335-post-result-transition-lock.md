# EXP-335 pre-result post-result transition lock

This document freezes the allowed successor transition for **every** preregistered EXP-335 disposition before the authoritative final reducer is visible.

It is procedural only. It does not modify EXP-335 scientific bytes, thresholds, world population, training schedule, projection geometry, evidence, or reducer.

- **AFIXED_FULL32_FOUNDATION_REENTERED_BOTH** → foundation established; authorize only C_NRS_CORE full-32 Stage-A **design/preregistration** using the balanced CONTROL foundation. Projection is not required by this result.
- **AFIXED_FULL32_FOUNDATION_REENTERED_CONTROL_ONLY_PROJECT_REGRESSION** → foundation established through CONTROL; authorize only C_NRS_CORE design/preregistration on CONTROL. The full-32 projector is unsafe as the default successor foundation.

- **SHAM_FULL32_MISMATCH** → measurement non-perturbation localization only.

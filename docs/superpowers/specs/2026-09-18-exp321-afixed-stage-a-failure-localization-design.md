## Why EXP-321 exists

EXP-319 stopped at its first causal gate because the supervised fixed control `A_FIXED` failed Stage A.

The selected frozen `A_FIXED@1e-4` checkpoint at step 1024 has:

- initial answer-only loss: `343.3998213217292`;
- final answer-only loss: `2.3282841685897444`;
- final/initial loss fraction: about `0.00678`, comfortably below the EXP-319 maximum `0.25`;
- teacher-forced answer-token accuracy: `0.7711267605633803`;
- greedy exact match: `0.28125`;
- EOS correctness: `1.0`;
- invalid output rate: `0.0`;
- non-finite event count: `0`.

Per-family greedy exact match at step 1024:

- `algorithmic-sequence-transform = 0.0`
- `generator-heldout-abstract-transformation = 0.625`
- `iterative-grid-and-maze = 0.5`
- `language-sequence-control = 0.0`

The selected-LR trajectory is also non-monotonic in loss:

- step 128: loss `8.794675591546046`, token accuracy `0.11619718309859155`, exact `0.0`;
- step 512: loss `1.8019380050762164`, token accuracy `0.6267605633802817`, exact `0.21875`;
- step 1024: loss `2.3282841685897444`, token accuracy `0.7711267605633803`, exact `0.28125`.

The higher frozen LR `3e-4` is worse at step 1024:

- loss `2.5205218226507036`;
- token accuracy `0.7640845070422535`;
- exact `0.15625`.

This proves that the control stack performs substantial finite optimization, but it does **not** identify why teacher-forced learning fails to become high-exact greedy behavior.

EXP-321 localizes that failure before any new training intervention is authorized.

## Scientific question

Given the immutable EXP-319 selected `A_FIXED@1e-4` Stage-A checkpoint at step 1024, which failure class best explains the missing local learnability?

EXP-321 distinguishes:

1. **teacher-forced representation/optimization insufficiency** — the model still cannot predict the frozen answers correctly when supplied the true prefix;
2. **autoregressive rollout / exposure failure** — teacher-forced full-answer prediction is strong but greedy free-running generation diverges after early mistakes;
3. **effort-distribution mismatch** — the checkpoint behaves materially differently across the effort values used during training `(1,2,4,8)`, while EXP-319 gates only at effort `4`;
4. **unused-vocabulary competition** — substantial probability mass is wasted on the 4,348 tokenizer IDs that are not legal generated bytes/control EOS under the EXP-319 decode contract;
5. **family-localized failure** — the failure is concentrated in long/structured sequence families instead of being uniformly global.

EXP-321 is deliberately post-hoc and gradient-free. It uses the already-sealed checkpoint and frozen Stage-A worlds.

## Measurement A — teacher-forced token geometry

For each world and each effort, run one forward pass on the complete frozen encoded example under the true prefix.

Measure over answer targets including EOS:

- answer token count;
- top-1 teacher-forced token accuracy;
- teacher-forced full-answer exactness (every answer target, including EOS, is top-1 correct);
- mean correct-token probability;
- mean correct-token rank in the full 4,608-way vocabulary;
- mean correct-token rank restricted to the legal-generation set;
- mean total probability mass on the legal-generation set;
- mean total probability mass on unused IDs `260..4607`;
- first teacher-forced top-1 error position, or null when exact.

All softmax/ranking measurements must be derived from the same immutable logits used for top-1 scoring.

## Measurement B — frozen greedy rollout

For each world and each effort, generate greedily from the prompt using the inherited 96-token cap.

Measure:

- exact answer;
- generated token IDs;
- EOS correctness;
- invalid-output flag;
- generated answer length;
- first mismatch position against the canonical answer token sequence;
- longest correct prefix length;
- whether the first generated answer token is correct.

No semantic post-correction is permitted.

## Measurement C — legal-vocabulary masked counterfactual

This is an inference-only counterfactual, not a new model.

At every greedy generation step, set logits for every token outside:

`{EOS} union {byte IDs 4..259}`

to negative infinity before argmax.

Do **not** renormalize or train.

Measure the same rollout metrics as Measurement B.

This asks one narrow causal question: would forbidding impossible output IDs materially change greedy behavior?

The masked result is never treated as a new architecture or as a capability claim.

## Measurement D — family and answer-length localization

Aggregate A/B/C by:

- task family;
- effort;
- canonical answer byte length;
- first-error position bucket.

At minimum report for each family:

- teacher-forced token accuracy;
- teacher-forced full-answer exact;
- greedy exact;
- masked-greedy exact;
- mean correct-prefix fraction;
- mean unused-vocabulary probability mass.

### Primary causal rules

All calculations use effort `4` unless the rule explicitly references the effort grid.

1. `TEACHER_FORCED_FOUNDATION_INSUFFICIENT`
   - teacher-forced token accuracy < `0.99`, **or**
   - teacher-forced full-answer exact < `0.90`,
   - and neither effort mismatch nor unused-vocab counterfactual independently clears both thresholds.

2. `ROLLOUT_EXPOSURE_BOTTLENECK`
   - teacher-forced token accuracy >= `0.99`;
   - teacher-forced full-answer exact >= `0.90`;
   - unmasked greedy exact < `0.90`;
   - masked greedy does not improve exact by >= `0.25`.

3. `EFFORT_MISMATCH_EVIDENT`
   - at least one effort in `(1,2,8)` exceeds effort-4 greedy exact by >= `0.25`,
     **or** exceeds effort-4 teacher-forced full-answer exact by >= `0.25`;
   - the winning effort's metric must be based on all 32 frozen worlds.

4. `UNUSED_VOCAB_COMPETITION_EVIDENT`
   - masked greedy exact exceeds unmasked effort-matched greedy exact by >= `0.25`,
     **or**
   - masked teacher-forced top-1 recovery would convert >= `25%` of previously wrong
     answer targets to correct solely by excluding illegal IDs.

5. `MIXED_TRAINING_STACK_FAILURE`
   - two or more causal rules above are simultaneously satisfied.

6. `NO_DOMINANT_LOCALIZED_CAUSE`
   - valid reproduction;
   - no rule above is satisfied.

If the teacher-forced floor is not met and no other causal intervention independently crosses its registered effect threshold, `TEACHER_FORCED_FOUNDATION_INSUFFICIENT` has precedence.

## Family-localization annotation

The primary disposition is accompanied by a non-authorizing annotation.

A family is marked `SEVERE` when both:

- teacher-forced full-answer exact < `0.50`;
- greedy exact < `0.25`.

A family is marked `ROLLOUT_GAP` when:

- teacher-forced full-answer exact - greedy exact >= `0.50`.

A family is marked `NO_SEVERE_LOCALIZATION` otherwise.

Annotations do not change the primary disposition.

# EXP-299 Native Fidelity Scaffold-Removal Court Design

## Authority

EXP-299 / `H-NATIVE-01` is authorized only by the sealed EXP-298 DEVELOPMENT disposition `CROSS_DOMAIN_FIDELITY_TRANSFER_RECURRENT`, whose scope is `DESIGN_EXP299_SCAFFOLD_REMOVAL_COURT_ONLY`. The EXP-298 scientific branch remains sealed and unmerged. This EXP-299 lineage starts from the exact EXP-298 pre-data implementation substrate `68e1205fd56e5b1acb8f02cea56fc9af1a881734`, before any EXP-298 release marker existed, so the reusable deterministic domain/court machinery is inherited without mutating the sealed EXP-298 branch. EXP-300 remains unauthorized.

The frozen Stage-A protocol is unchanged and this lane MUST NOT modify `protocols/stage_a_v1.json` or `protocols/stage_a_v1.sha256`.

## Question

Can the model internalize enough of the EXP-298 fidelity/verification signal that a material cross-domain fidelity advantage remains when the exact behavioral court is removed completely from held-out causal inference?

This is an internalization/scaffold-removal court. It does not establish unrestricted semantic understanding, arbitrary program verification, causal discovery, open-language reasoning, durable lifelong consolidation, or integrated V0.16 superiority.

## Pre-data representation correction

EXP-298's neural arms consumed SHA-256 source/candidate digests. Those digests are suitable as identity bindings but are intentionally pseudorandom with respect to semantic structure. A scaffold-removal court that gives the held-out model only hashes would make native transfer fail by construction rather than test internalization.

EXP-299 therefore freezes a new **model-visible structural encoding** before any held-out DEVELOPMENT data exist. It is derived only from public source/candidate objects and is shared byte-for-byte by both arms. Hashes remain receipt identities but are not the neural semantic representation.

The encoder MUST NOT consume `is_faithful`, `stratum`, court decisions, witnesses, evaluator labels, or any field derived from them.

## Model-visible structural encoding

Each domain maps source and candidate objects to a fixed-width canonical vector. The encoding is deterministic, bounded, and exposes only information already present in the public problem object.

### Code invariant encoding

Encode, in canonical order:

- the three finite variable-domain cardinalities;
- every transition row as normalized `(pre_x, pre_y, pre_flag, post_x, post_y, post_flag)` values;
- a bit for every finite post-state indicating invariant membership.

No stratum name or faithful label is encoded.

### Causal diagnosis encoding

Encode, in canonical order:

- exogenous/endogenous symbol positions through a frozen local symbol table;
- each equation's target position, operator one-hot (`identity`, `not`, `xor`, `and`, `or`) and argument positions;
- intervention-alias source/target positions;
- diagnosis-target position.

No intervention probe outcome or evaluator comparison result is encoded.

### Grounded-language encoding

Encode the public finite semantic AST recursively using frozen operator ids (`pred`, `rel`, `not`, `and`, `or`, `exists`, `forall`), argument/binder positions, predicate/relation symbol positions, entity count, `domain_kind`, and `open_language` flag. Pad/truncate only at a frozen bound that is larger than every V1 AST generated by the domain family; truncation of any V1 candidate is a hard execution failure.

### Pair representation

The neural arm receives both structural vectors and explicit symmetric comparison channels:

- `source_features`;
- `candidate_features`;
- `candidate_features - source_features`;
- `abs(candidate_features - source_features)`.

This makes semantic differences learnable without giving the model the evaluator's answer. Both arms receive identical pair features.

## Core causal contrast

EXP-299 uses two matched neural arms with byte-identical initialization and geometry:

1. `binary_supervision_control`: learns only the frozen primary binary fidelity target on fit examples.
2. `court_teacher_then_native`: learns the same primary target plus fixed auxiliary teacher targets derived from the fit-time exact-court receipt.

The exact court is a **training-time teacher**, not a deploy-time input channel. Neither arm receives a court receipt as a forward-pass feature during fit or held-out evaluation.

The auxiliary teacher vector contains only properties of the fit-time exact comparison:

- accept/reject/inconclusive one-hot;
- witness direction (`source_to_candidate`, `candidate_to_source`, none);
- exhaustive-completion bit;
- normalized probe fraction.

`court_teacher_then_native` predicts this vector from structural features using an auxiliary head. The control has an architecturally matched auxiliary head and executes the same FLOP path, but its auxiliary loss weight is exactly zero. Thus architecture, forward compute, primary labels, examples, optimizer, and batch order are matched; the only causal intervention is auxiliary court-teacher supervision during fit.

During held-out evaluation the court exists evaluator-side only. Neither arm receives teacher targets, receipts, witnesses, labels, or strata before producing its neural authority score.

## Domains

Reuse the frozen deterministic EXP-298 domain families and exact court semantics:

- `code_invariant`
- `causal_diagnosis`
- `grounded_language_ambiguity`

The frozen candidate strata remain unchanged. Evaluation labels (`is_faithful`, `stratum`) are evaluator-only. No evaluation candidate's exact-court decision, witness, faithful label, or stratum may enter model fitting or held-out causal inputs.

## Data partition and independence

For each `(root, domain)` create two deterministic non-overlapping partitions:

- fit: 96 replicates, 16 candidates/replicate;
- held-out evaluation: 32 replicates, 16 candidates/replicate.

Fit and evaluation use domain-separated RNG labels and independently derived environment seeds. Candidate identity digests must be disjoint across partitions. Held-out exact truth/court receipts are computed only after model fit is complete and consumed only by the evaluator.

Each root therefore evaluates 1,536 held-out candidates and 4 roots evaluate 6,144 held-out candidates.

## Model and fit contract

Both arms use identical V1 geometry:

- structural feature width `128` per source/candidate object;
- `d_model=64`;
- `hidden_size=64`;
- `target_parameters=500000`;
- primary authority threshold `0.5`.

Both arms predict binary fidelity from neural logits. The primary fit target is fit-time exact-court truth (`court_accept = 1`, exact `court_reject = 0`). `court_inconclusive` examples are excluded from gradient targets and their count is reported; no root may pass if any fit or evaluation candidate is inconclusive under the frozen exact-probe bound.

Both arms see the same fit examples in the same order and use the same primary target. The teacher arm additionally receives the frozen auxiliary court target described above. Auxiliary loss is mean squared error over the fixed teacher vector with frozen weight `0.25`; the control computes the same auxiliary prediction but multiplies its auxiliary loss by exactly `0.0`.

Frozen optimizer geometry:

- AdamW;
- learning rate `3e-4`;
- weight decay `1e-4`;
- one pass over the frozen fit set;
- batch size `32`;
- gradient clip norm `1.0`;
- binary primary loss weight `1.0`;
- teacher auxiliary loss weight `0.25` vs control `0.0`.

No threshold sweep, extra epochs, learning-rate tuning, auxiliary-weight tuning, root replacement, post-result domain removal, representation edit, or sample escalation is permitted after one-shot release.

## Native evaluation rule

After fit:

1. snapshot both model-state digests;
2. disable gradients;
3. expose only structural pair features and executable status to both arms;
4. prohibit receipt/teacher/witness/truth/stratum arguments on the native inference interface;
5. produce neural fidelity/authority scores exactly once for each held-out candidate;
6. only after prediction, evaluator-side exact court truth is used for scoring;
7. verify model state is byte-stable across held-out evaluation.

Authority is neural and uses the frozen `0.5` threshold on `authority_score` for both arms. Exact court acceptance cannot directly grant authority.

## Primary and protected endpoints

For each domain `d`:

- `BA_native[d]`: balanced accuracy of `court_teacher_then_native` after scaffold removal;
- `BA_control[d]`: balanced accuracy of `binary_supervision_control`;
- `native_gain[d] = BA_native[d] - BA_control[d]`;
- `wrong_authority_native[d]`;
- `faithful_rejection_native[d]`.

Frozen V1 success thresholds:

- `BA_native[d] >= 0.70` for all three domains;
- `native_gain[d] >= 0.10` for all three domains;
- `wrong_authority_native[d] <= 0.05` for all three domains;
- `faithful_rejection_native[d] <= 0.10` for all three domains.

The root primary endpoint is `min_d native_gain[d]`. Safety endpoints are conjunctive and cannot be traded against gain.

## Root decision

A canonical root returns `NATIVE_FIDELITY_SURVIVES_SCAFFOLD_REMOVAL` only when:

- all three domains meet every frozen primary/protected threshold;
- structural encoder audit proves no evaluator-only field is consumed;
- fit/eval candidate identities are disjoint;
- both arms are matched at initialization, parameter count, forward FLOPs, primary supervision, examples, and optimizer geometry;
- held-out inference accepts no receipt/teacher/witness/truth/stratum input;
- model state is unchanged during held-out evaluation;
- raw rows reconstruct every aggregate exactly;
- all evidence-boundary flags remain false.

Otherwise it returns `NATIVE_FIDELITY_NOT_ESTABLISHED`.

## Portability hardening inherited from EXP-298 incident

EXP-298 exposed a cross-process byte-reconstruction portability defect after all root receipts had already self-validated. EXP-299 therefore freezes an explicit validator portability rule before data:

- canonical receipts may contain only JSON-stable scalar/list/map values with string map keys;
- no process-local object identity, storage address, unordered set, Python hash randomization, or device-dependent raw storage representation may enter deterministic reconstruction;
- model-state digests serialize tensor values through the repository's scalar-safe deterministic byte primitive rather than raw process/device storage views;
- root validators must be executed in both producer process and a fresh subprocess in pre-data CI on synthetic fixture roots;
- cross reducer validates sealed receipt bytes/digests and deterministic semantic recomputation without requiring process-unstable object reconstruction.

This is pre-data hardening for a new experiment, not a reinterpretation or repair of the sealed EXP-298 result.

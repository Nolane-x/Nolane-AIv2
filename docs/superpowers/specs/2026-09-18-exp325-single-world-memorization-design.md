## Question

EXP-324 removed cross-family interference but preserved within-family interaction: each family arm cycled eight worlds for 256 updates. Every individual world therefore received exactly 32 training exposures.

No family reached the teacher-forced floor.

EXP-325 asks the next narrower causal question:

> If the same 32 exposures are devoted to a single world starting from the exact same immutable step-2048 state, can that world itself be memorized to the existing teacher-forced floor?

This changes **interference**, not exposure budget.

## Exact population

The court uses all 32 Stage-A root-0 worlds generated by `exp319-worlds-v1`:

- four frozen families;
- indices 0 through 7 in every family;
- stage `A_SANITY`;
- root `0`.

A world is identified by the exact tuple `(generator_version, family, stage, root, index)`. Runtime must materialize all 32 worlds and reject duplicates or missing tuples.

## Training geometry

For each world independently:

- LR remains exactly `5e-5`;
- optimizer remains AdamW with inherited moments;
- tokenizer/objective/weight decay/gradient clipping/effort cycle remain unchanged;
- exactly 32 optimizer updates are allowed;
- evaluate after local updates 8, 16 and 32.

The 32-update budget is deliberately matched to EXP-324: 256 updates / 8 worlds = 32 exposures per world.

## Primary gate

A world passes if at any registered checkpoint both hold:

- teacher-forced answer-token accuracy >= `0.99`;
- teacher-forced full-answer exact >= `0.90`.

Because each arm contains one world, the full-answer metric is binary in practice; the registered 0.90 threshold therefore requires an exact answer.

Greedy exact and loss are secondary.

## Decision order

1. `INVALID_WORLD_ISOLATION`: malformed/missing/duplicate world geometry, state mismatch, non-finite event, missing checkpoint or evidence-integrity failure.
2. `ALL_WORLDS_SINGLE_FIT`: all 32 worlds pass.
3. `SOME_WORLDS_SINGLE_FIT`: at least one but fewer than 32 worlds pass.
4. `NO_WORLDS_SINGLE_FIT`: valid execution and zero worlds pass.

Reducer must also report pass counts per family and exact failed-world identities.

## Interpretation

### ALL_WORLDS_SINGLE_FIT

Matched per-world exposure is sufficient when worlds are completely isolated. This supports within-family multi-world optimization interference as a contributor. It does not uniquely identify gradient conflict, ordering, optimizer-state contamination or another mechanism.

### SOME_WORLDS_SINGLE_FIT

The failure is heterogeneous. The result localizes specific difficult worlds while leaving residual interference effects viable for worlds that do fit individually.

### NO_WORLDS_SINGLE_FIT

Cross-world interference is not required to reproduce the failure at the matched 32-update budget. The next diagnostic must distinguish per-world budget insufficiency from representation/objective/optimization barriers. This still does not establish a 10M architectural capacity ceiling.

## Hard non-claims

EXP-325 cannot authorize scaling, EXP-320 implementation, or reinterpret earlier experiments. Failure at 32 single-world updates cannot be extrapolated to unlimited memorization budget.

All authorization flags remain hard-coded false.
